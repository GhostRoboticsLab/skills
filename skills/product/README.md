# Product

Promoted. Each skill here was used in shipped work and ships in the `ghostlabs-skills` plugin. These are about what users get: reviewing the whole product, and showing a release.

## Model-invoked

The agent reaches for these when the task fits, and you can call them by name. None yet.

## User-invoked

Only you can start these.

- **[app-critic](./app-critic/SKILL.md)**: Score the whole product on a scorecard, every score with evidence, and turn what it finds into prioritised stories.
- **[whats-new-clip](./whats-new-clip/SKILL.md)**: For each release, cut a short What's New clip from the product's real screens: words first, filmed on the real build, reviewed before a person sees it.
